# FKP_2 — Fast Keyboard

نسخه اولیه پروژه کیبورد نرم‌افزاری Android.

## مبنا
چیدمان و قوانین این نسخه بر اساس تصویر مرجع و فایل Fast Keyboard README است.

قانون اصلی: فقط تغییر صریح کاربر اعمال شود؛ هیچ کلید یا قابلیت اضافی بدون درخواست اضافه، حذف یا جابه‌جا نشود.

## وضعیت نسخه 1.0
- سرویس واقعی Android Input Method
- چیدمان اصلی فارسی
- نوار ابزار
- نوار پیشنهاد
- اعداد
- حروف فارسی
- Caps
- Space
- علائم نگارشی
- فلش‌های مکان‌نما
- Backspace
- Clipboard actions پایه
- Resize به عنوان دکمه پایه برای تکمیل در مرحله بعد

## ساخت
Workflow در `.github/workflows/android.yml` قرار دارد و با Push به main یا اجرای دستی ساخته می‌شود.

این نسخه «اسکلت اولیه قابل توسعه» است و قابلیت‌های پیچیده‌ای مانند تاریخچه 100تایی، امکانات، Resize کامل و Mouse در مراحل بعدی تکمیل می‌شوند.
