# FKP_2 — Fast Keyboard

نسخه 1.1 — پایهٔ کاری متوسط برای ادامه توسعه.

## امکانات فعال این نسخه
- نمایش واقعی صفحهٔ کیبورد در Input Method.
- چیدمان فارسی مرجع: نوار ابزار، پیشنهادها، اعداد، دو ردیف حروف، ردیف سوم و ردیف پایین.
- اعداد فارسی در حالت عادی.
- حالت Symbols با دکمه 123 / !@... .
- Space، Backspace، Enter نیست و مطابق چیدمان مرجع اضافه نشده است.
- فلش‌های چپ، راست، بالا و پایین.
- Caps برای تغییر حالت داخلی.
- Copy All، Copy Screen، Paste، Cut، Undo و Redo به‌صورت عملیاتی پایه.
- تاریخچه تا 100 ورودی ثبت‌شده و پنجره انتخاب تاریخچه.
- امکانات شامل حرکات عربی/اعراب و چند ابزار پایه.
- پنجره Emoji پایه.
- Globe برای انتخاب کیبورد دیگر.
- Resize به‌صورت پایه برای تست اندازهٔ کیبورد.

## فعال‌سازی
1. APK را نصب کنید.
2. برنامه FKP_2 را باز کنید.
3. «تنظیمات کیبورد» را بزنید.
4. FKP_2 را فعال کنید.
5. «انتخاب کیبورد» را بزنید و FKP_2 را انتخاب کنید.
6. یک محل ورود متن را باز کنید.

## GitHub Actions
Workflow با `push` تنظیم شده است؛ نام Commit مهم نیست. در MGit:
`All to Stage → Commit → Push`
پس از Push، `FKP_2 Android Build` باید خودکار اجرا شود. Rebuild فقط برای اجرای دوبارهٔ یک اجرای قبلی لازم است.

## قانون توسعه
چیدمان مرجع فقط با درخواست صریح کاربر تغییر می‌کند. قابلیت‌های بعدی مرحله‌به‌مرحله اضافه می‌شوند و نباید بدون درخواست کلید یا دکمه‌ای حذف، جابه‌جا یا اضافه شود.
